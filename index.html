Bandlab Playlist

v.0.4.0 (2026. 09. 12)

개요
• 2024년부터 작업한 밴드랩 곡 중 일부(매우 짧은 스케치 등)만 제외한 플레이리스트입니다.
• 작곡가: Mudan Guto, peled723, Holari Crab
• 웹 제작: Mudan Guto

기능
• 라이트/다크 모드: 물음표 버튼 옆 해/달 아이콘을 눌러 전환합니다.
• 곡 선택(우측 상단): 원하는 곡을 선택하여 재생합니다.
• 랜덤 아이콘: 켜져 있는 경우, 모든 곡을 무작위로 재생합니다.
• 오토 아이콘: 누를 때마다 [꺼짐 → 자동재생(다음 곡 자동 진행) → 한 곡 반복("1" 표시)] 순서로 전환됩니다.
• 진행바를 클릭하거나 드래그하여 이동할 수 있습니다.
• 우측 슬라이드를 조절하여 볼륨을 조절할 수 있습니다.
• 이전 곡, 재생/일시정지, 다음 곡 버튼을 눌러 기능을 수행할 수 있습니다.

참고
• 곡 정렬은 ABC 순입니다(대소문자 구분 X).
• RANDOM 기능을 켠 상태에서는 이전 곡 버튼 사용이 불가합니다.
• RANDOM 기능을 켠 상태에서 곡 선택 기능을 이용하면 셔플 목록이 초기화됩니다.

버전
• v.0.4.0 (2026. 09. 12)
- 곡 제목/시간 표시에 퓨처리스틱 디스플레이·모노스페이스 폰트 적용
- 곡 제목/프로듀서 표기를 재생바 기준 중앙으로 이동, 가사창 확대
- 볼륨바 뒤 뉴모피즘 원형 배경 제거
- 셔플 버튼이 눌리지 않던 클릭 가로채기 버그 수정
- 오토 버튼을 [꺼짐 → 자동재생 → 한 곡 반복] 3단계 토글로 변경

• v.0.3.0 (2026. 09. 12)
- UI 전면 개편: 뉴모피즘 미니멀 라이트 테마 적용
- 배속 기능 및 관련 연출(10배속 스컬모드 등) 제거
- 랜덤/오토 버튼을 아이콘 기반으로 변경
